## The exposure

The custody correction of 2026-11-21 removed two SEG
translation strings from `corpus/corpus.json` and replaced the
corpus's false public-domain licensing basis. The removed
strings, and the false basis, remain in this repository's
public git history at commit `173882a2`, in a repository
carrying an MIT LICENSE file. No Eteocypriot record had stated
a position on that exposure. This note states it.

## The program's position

What is published in a public git history cannot be
retracted: the history is mirrored and cloned beyond the
program's control, and rewriting it would falsify the record
the program's own discipline depends on. The program therefore
does not attempt retraction. The custody correction governs
the working record and all future citation: the removed
strings are not program material, are not to be quoted from
the historical commit as program output, and the false
licensing basis is superseded wherever it appears. Any future
citation of the corpus is to the corrected file at its current
version (1.1.0), never to the historical bytes. This is the
same posture the Meroitic program took toward its published
Otten-derived derivatives: exposure stated on the record,
correction governing forward.
